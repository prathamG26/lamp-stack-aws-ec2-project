# LAMP Stack Web Application on AWS EC2

## Project Overview
Deployed a LAMP (Linux, Apache, MariaDB, PHP) web application on AWS EC2.

## Technologies Used
- AWS EC2
- Amazon Linux 2023
- Apache HTTP Server
- PHP
- MariaDB/MySQL
- Linux

## Features
- Configured Apache web server
- Connected PHP application with MariaDB database
- Retrieved user records from database
- Hosted application using EC2 public IP

## Architecture

User Browser
↓
AWS EC2
↓
Apache HTTP Server
↓
PHP Application
↓
MariaDB Database
